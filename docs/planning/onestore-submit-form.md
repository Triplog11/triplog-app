## 2. 앱 소개

### 한 줄 소개 (50자 이내)

```
발 닿은 곳이 기록이 되고, 기록이 도감이 되는 여행 수집 앱
```

### 상세 설명

```
전국을 여행하며 발자국을 모아 보세요.

트립로그는 여행의 순간을 기록하고 수집하는 앱입니다.
전국 시·군·구의 관광지를 직접 방문해 인증하면,
그곳의 랜드마크 카드가 나만의 도감에 담깁니다.

■ 방문할수록 진해지는 나만의 지도
방문한 지역이 늘어날수록 전국 지도가 점점 파랗게 채워집니다.
어디를 다녀왔고 어디가 남았는지 한눈에 확인하세요.

■ 랜드마크 카드 수집
관광지마다 고유한 카드가 준비되어 있습니다.
일반, 희귀, 영웅, 전설 네 등급의 카드를 모아 도감을 완성해 보세요.

■ 현재 위치로 찾는 방문 인증
지금 있는 곳 주변의 관광지를 자동으로 찾아 줍니다.
가까운 순서로 보여드리니 바로 인증하고 카드를 받으세요.

■ 여행의 순간을 기록
방문한 곳의 별점과 후기를 남기면 여행 기록이 차곡차곡 쌓입니다.
언제 어디를 다녀왔는지 나중에 다시 꺼내 볼 수 있습니다.

■ 미션과 랭킹
매일 새로운 미션이 주어집니다.
방문 인증과 기록 작성으로 경험치와 점수를 모아
레벨을 올리고 다른 여행자들과 순위를 겨뤄 보세요.

■ 뱃지와 칭호
특정 조건을 달성하면 뱃지와 칭호를 획득합니다.
대표 뱃지와 칭호를 골라 프로필을 꾸며 보세요.

관광 정보는 한국관광공사 국문 관광정보 서비스(TourAPI)를 활용합니다.
```

### 업데이트 내용 (첫 등록이므로 간단히)

```
트립로그 첫 출시입니다. 전국의 관광지를 방문하고 나만의 여행 도감을 만들어 보세요.
```

## 4. 권한 사용 사유

원스토어는 민감 권한에 대한 설명을 요구합니다.

**위치 권한 (ACCESS_FINE_LOCATION, ACCESS_COARSE_LOCATION)**

```
관광지 방문 인증 시 이용자가 현재 어느 시·군·구에 있는지 확인하고, 주변 관광지까지의
거리를 계산하기 위해 단말기의 위치를 사용합니다. 위도·경도 좌표는 단말기 안에서만
사용하며 서버로 전송하거나 저장하지 않습니다. 백그라운드 위치 수집은 하지 않습니다.
위치 권한을 허용하지 않아도 지역을 직접 선택해 모든 기능을 이용할 수 있습니다.
```

## 7. 제출 절차

1. Apps → `+ 신규 상품 등록`
2. 위 1~2절 정보 입력
3. APK 업로드 (`TripLog-v1.0.0-onestore.apk`)
4. 3절 이미지 등록
5. 4절 권한 사유, 5절 약관 URL 입력
6. 6절 등급 설문 응답
7. 판매 국가: 대한민국
8. 심사 요청 → 통상 1~3영업일

## 9. 이후 업데이트 시

`frontend/eas.json` 의 `onestore` 프로파일로 빌드하면 versionCode가 자동으로 올라갑니다.

```bash
cd frontend
eas build --platform android --profile onestore
```

구글 플레이도 올릴 경우 `production` 프로파일로 AAB를 만들면 됩니다.
