## 3. 스토어 등록 정보

### 3.1 짧은 설명 (50자 이내)

> 발 닿은 곳이 기록이 되고, 기록이 도감이 되는 여행 수집 앱

### 3.2 긴 설명

```
전국을 여행하며 발자국을 모아 보세요.

트립로그는 여행의 순간을 기록하고 수집하는 앱입니다.
전국 시·군·구의 관광지를 직접 방문해 인증하면,
그곳의 랜드마크 카드가 나만의 도감에 담깁니다.

■ 방문할수록 진해지는 나만의 지도
방문한 지역이 늘어날수록 전국 지도가 점점 파랗게 채워집니다.
어디를 다녀왔고 어디가 남았는지 한눈에 확인하세요.

■ 랜드마크 카드 수집
관광지마다 고유한 카드가 준비되어 있습니다.
일반, 희귀, 영웅, 전설 네 등급의 카드를 모아 도감을 완성해 보세요.

■ 여행의 순간을 기록
방문한 곳의 별점과 후기를 남기면 여행 기록이 차곡차곡 쌓입니다.
언제 어디를 다녀왔는지 나중에 다시 꺼내 볼 수 있습니다.

■ 미션과 랭킹
매일 새로운 미션이 주어집니다.
방문 인증과 기록 작성으로 경험치와 점수를 모아
레벨을 올리고 다른 여행자들과 순위를 겨뤄 보세요.

■ 뱃지와 칭호
특정 조건을 달성하면 뱃지와 칭호를 획득합니다.
대표 뱃지와 칭호를 골라 프로필을 꾸며 보세요.

관광 정보는 한국관광공사 국문 관광정보 서비스(TourAPI)를 활용합니다.
```

### 3.3 위치 정보 이용 안내 (심사 시 기재)

원스토어 심사에서 위치 권한 사용 사유를 묻는 경우 다음과 같이 기재합니다.

> 관광지 방문 인증 시 이용자가 현재 어느 시·군·구에 있는지 확인하기 위해 단말기의 위치를 사용합니다. 위도·경도 좌표는 단말기 안에서만 사용하며 서버로 전송하거나 저장하지 않습니다. 백그라운드 위치 수집은 하지 않습니다.

### 3.4 스크린샷

원스토어는 최소 3장, 권장 해상도는 1080×1920입니다. `docs/design/screens-2026-08-27/` 에 촬영본이 있으나, 이번 변경(지도 색상, 인증 플로우)이 반영된 화면으로 다시 촬영해야 합니다.

제출할 화면 5장을 다음과 같이 제안합니다.

1. 홈 — 방문률에 따라 색이 채워진 전국 지도
2. 도감 — 수집한 랜드마크 카드 목록
3. 인증 — 주변 랜드마크 선택 화면
4. 인증 완료 — 보상 내역 화면
5. 마이 — 프로필과 레벨, 뱃지

## 4. 개인정보 처리방침 공개 URL 마련

원스토어는 개인정보 처리방침을 웹에서 접근할 수 있는 URL로 제출하도록 요구합니다. 다음 세 가지 중 하나를 택하면 됩니다.

| 방법 | 장점 | 단점 |
|---|---|---|
| GitHub Pages | 저장소에 이미 문서가 있어 추가 비용이 없고 갱신이 쉽습니다. | 저장소가 비공개인 경우 별도 공개 저장소가 필요합니다. |
| 노션 공개 페이지 | 팀이 이미 노션을 쓰고 있어 접근이 쉽습니다. | 주소가 길고 노션 브랜딩이 노출됩니다. |
| 기존 서버에 정적 페이지 추가 | 도메인(triplog11.store)을 그대로 쓸 수 있어 가장 깔끔합니다. | 백엔드에 정적 리소스 경로를 추가해야 합니다. |

**권장**: `https://triplog11.store/privacy` 와 `https://triplog11.store/terms` 로 게시하는 방법입니다. 이미 도메인과 인증서가 준비되어 있으므로 백엔드에 정적 HTML 두 개만 추가하면 됩니다. 백엔드 담당자에게 요청이 필요합니다.

## 5. 빌드와 제출 절차

### 5.1 원스토어용 APK 빌드

```bash
cd frontend
eas build --platform android --profile onestore
```

`onestore` 프로파일은 `production` 을 상속하되 APK로 산출합니다. 원스토어는 AAB도 받지만 APK 업로드가 더 간편합니다.

### 5.2 구글 플레이도 함께 준비하는 경우

```bash
cd frontend
eas build --platform android --profile production
```

`production` 프로파일은 AAB를 산출하며 `autoIncrement` 가 켜져 있어 빌드할 때마다 versionCode가 자동으로 올라갑니다.

### 5.3 제출 순서

1. 원스토어 개발자 센터(https://dev.onestore.co.kr)에 로그인합니다.
2. 앱 등록 후 위 3절의 정보를 입력합니다.
3. APK를 업로드합니다.
4. 개인정보 처리방침 URL을 입력합니다.
5. 콘텐츠 등급을 자체 분류합니다(게임이 아니므로 별도 심의 기관을 거치지 않습니다).
6. 심사를 신청합니다. 통상 1~3영업일이 걸립니다.
